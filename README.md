# 전략 윷놀이

팀 협력 + 개인 경쟁이 동시에 가능한 웹 기반 윷놀이 게임.
빌드 없이 `index.html`을 브라우저에서 바로 열면 실행된다.

---

## 실행

```bash
open index.html
```

외부 의존성: Three.js (CDN, 자동 로드)

---

## 파일 구조

```
WorkshopGame/
├── index.html          # 진입점. 화면 3개(setup/game/winner) + 3D 오버레이
├── css/
│   └── style.css       # 전체 스타일 (라이트 테마, 변수 기반)
└── js/
    ├── state.js        # 게임 상태 모델 + 순수 헬퍼 함수
    ├── board.js        # 보드 그래프, SVG 렌더링, 경로 계산
    ├── game.js         # 윷 로직, 이동/충돌/스택 처리
    ├── setup.js        # 4단계 설정 화면 (드래그앤드롭 팀 배치)
    ├── ui.js           # UI 컨트롤러 (화면 전환, 패널 업데이트)
    ├── yut3d.js        # Three.js 3D 윷 던지기 물리 시뮬레이션
    └── main.js         # 이벤트 연결, 턴 흐름 제어
```

## 주요 개념

### 게임 상태 (`state.js`)
- 싱글턴 `gameState` — `getState()` / `setState()`로 접근
- `phase`: `SETUP` → `GAME` → `FINISHED`
- `pendingYutResults`: 사용 대기 중인 이동 칸 수 배열 (윷/모 추가턴 지원)
- `canRollAgain`: 윷 던지기 버튼 활성화 여부

### 보드 그래프 (`board.js`)
- 노드 30개: 외곽 트랙 0–20, 대각선 21–29, 중앙 24
- 위치 0 = 출발선, 20 = 가상 완주 착지점, `'EXIT'` = 완주
- `getLandingOptions(fromPos, steps, prevPos)` — BFS로 가능한 착지 위치 계산
  - `steps < 0` (빽도) 시 역방향 이동 지원
  - 중앙(24) 분기는 `prevPos`로 방향 결정

### 윷 결과
| 결과 | steps | 조건 |
|------|-------|------|
| 모   | +5    | 뒤 0개 |
| 도   | +1    | 뒤 1개 (빽도 막대 제외) |
| 개   | +2    | 뒤 2개 |
| 걸   | +3    | 뒤 3개 |
| 윷   | +4    | 뒤 4개 |
| 빽도 | -1    | 뒤 1개이며 빽도 막대(index 0)가 뒤 |

### 3D 윷 던지기 (`yut3d.js`)
- Three.js + 커스텀 물리 엔진 (외부 물리 라이브러리 없음)
- **꾹 누르는 동안**: 판이 진동하며 막대기가 튀어다님
- **손을 떼면**: 위쪽 impulse → 낙하 → 앞/뒷면으로 결과 결정
- 빽도 막대(index 0): 빨간 배경 + 빨간 X 3개 (Canvas 텍스처)

### 말 종류
- **팀 말**: 팀 공유, 팀원 누구나 이동 가능
- **개인 말**: 플레이어 본인만 이동 가능
- 같은 팀 말이 같은 칸 → 업기 (stackCount 누적)
- 상대 팀 말과 같은 칸 → 잡기 (상대 말 대기 복귀 + 추가 턴)

### 승리 조건
- **개인 승리** (우선): 자신의 개인 말 전부 완주
- **팀 승리**: 팀 말 전부 완주

## 전역 객체

| 객체 | 역할 |
|------|------|
| `BOARD` | 보드 그래프, SVG 렌더링 |
| `GAME`  | 윷 로직, 이동 계산 |
| `UI`    | 패널/화면 업데이트 |
| `SETUP` | 설정 흐름 |
| `YUT3D` | 3D 던지기 시뮬레이션 |
| `showNotification(msg, type)` | 전역 알림 함수 |
